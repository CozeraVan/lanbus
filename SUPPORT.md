# Support

- Read [docs/overview.en.md](docs/overview.en.md) / [docs/overview.zh-CN.md](docs/overview.zh-CN.md) first.
- For setup problems, run:
  ```bash
  lanbus doctor
  lanbus discover --json
  curl http://HUB:8788/health
  lanbus local status
  ```
- Open a GitHub issue with OS, version (`lanbus --version`, `bin/lanbusd --version`),
  exact command, expected/actual behavior, and redacted logs.
- Do not paste tokens, private keys, private IPs of other people, or customer data.
