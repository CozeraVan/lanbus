# Code of Conduct

We want lanbus to be a useful, low-drama project for people running agents on
their own machines.

## Expected behavior

- Be specific and technical. Reproduce problems with logs, versions, and steps.
- Respect different operating systems, shells, and languages.
- Never post secrets, tokens, private keys, customer data, or other people's
  machine details in issues, pull requests, screenshots, or logs.
- Ask before running commands against someone else's machine.

## Unacceptable behavior

- Harassment, threats, discriminatory language, or personal attacks.
- Publishing private information or credentials.
- Deliberately disrupting another person's agents, machines, or network.
- Using the project to target systems without authorization.

## Enforcement

Maintainers may edit or remove comments, close issues, or block accounts that
violate this code. Report conduct concerns privately to the maintainers through
the repository's security/contact channel.

This code is adapted from the spirit of the Contributor Covenant.
